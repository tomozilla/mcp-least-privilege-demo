# AIエージェントにDBを触らせる前のチェックリスト

- [ ] **本番ではなく、開発用のプロジェクト**につないでいる
- [ ] URLに **`project_ref=`** が入っている（範囲）
- [ ] 書き込みが要らないなら **`read_only=true`**（書き込み禁止）
- [ ] **`features=`** で、必要な道具のグループだけ（道具）
- [ ] AIの操作は、**手動で承認**する設定のまま
- [ ] 「読み取り専用」でも、**見える範囲のデータは全部見える**と理解している（私の確認では、このロールはRLSをすり抜けました）
- [ ] データの中に、**他人が書いた文章**（問い合わせ・コメントなど）が混ざっている場合は、とくに注意（プロンプトインジェクション）
